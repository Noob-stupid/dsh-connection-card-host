fix: 小圆圈可见 + 换到正确的 composer 槽位

用户反馈「看不见连线按钮」。两个独立原因：

1. 样式从未进入页面
   - src/styles/tokens.css 是个死文件，没有任何地方 import 或注入它
   - 空 div 没有内容也没有尺寸 → 0px 高，完全不可见
   - 生态约定是 document.createElement('style') 注入 CSS 文本
     （客户端插件由 tsdown 打成单个 JS，没有 CSS sidecar 通道）
   - 改为 src/styles/tokens.ts：CSS 作为字符串打进 bundle + injectStyles()
   - 双保险：AnchorCircle/DragLine 的关键几何（尺寸/配色/pointer-events）
     全部内联，样式表挂了也不会出现「看不见的控件」或「点穿全屏」

2. 槽位选错
   - conversation.input.activity 是 kind=single + replaceRisk=shadows-shipped-ui：
     占位即替换出厂的活动指示器，且出厂 UI 先注册时 register() 直接抛
     single slot ... already has a registration（SlotCore 源码确认）
   - 改到 conversation.input.left：kind=list / replaceRisk=none /
     语义正是「composer 工具行左侧的紧凑控件」，自己的 id 会追加而非替换

顺带修正：
- DragLine 类名与新样式对齐；移除无效的 (DragLine as any).__release hack；
  按规格书实现 releasing -> shrinking(200ms) -> pulsing(300ms) -> onComplete
- 粒子循环夹住 dt，避免后台切回时的巨帧跳变
- ConnectionPanel/CardStack 类名统一 ccr- 前缀，避免与其他插件撞名
- 空状态文案改为可操作的提示

验证：cordis_inspect_query(conversation.input.left) 确认
     occupants=[{id:"connection-anchor", active:true}]，build 通过，热重载成功
